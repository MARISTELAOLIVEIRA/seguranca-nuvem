C1–C2 · conceitos

A rede como planta baixa

C1

VPC e sub-redes

A VPC é a sua rede particular dentro da nuvem. Ela se divide em sub-redes: a pública fala com a internet; a privada não.

Regra de ouro: banco de dados mora na sub-rede privada. Sempre.

C2

Grupos de segurança e ACLs

O grupo de segurança é o firewall de cada recurso: diz quem pode chegar e por qual porta. A ACL de rede é o firewall da sub-rede inteira.

Uma regra boa diz de onde vem o tráfego. 0.0.0.0/0 quer dizer "de qualquer lugar do mundo".

RecursoAceita
servidor webporta 443 de qualquer lugar
banco de dadosporta 3306 só do servidor web
acesso administrativosó de dentro, nunca de 0.0.0.0/0
EC1 · estudo de caso

O banco de dados com vista para a rua

A Escola Online Saber+ (fictícia) colocou o servidor web e o banco de dados na mesma sub-rede pública, com a porta do banco aberta para 0.0.0.0/0 "só para testar". Isso foi há oito meses.

Ninguém percebeu, porque o site funcionava normalmente.

Para discutir em grupo

  1. Quais são os riscos dessa configuração?
  2. Desenhe a rede corrigida: quais sub-redes e quais regras?
  3. Por que "só para testar" é uma frase perigosa na nuvem?

Caso fictício, criado para a aula.
