# ☁️🔐 Segurança em Nuvem

Site da disciplina **Segurança em Nuvem** (Segurança da Informação, 4º semestre, quartas de manhã) da
Faculdade de Tecnologia e Inovação Senac DF, com a Profa. Maristela (Stela).

**No ar:** https://maristelaoliveira.github.io/seguranca-nuvem/

## O que tem aqui

| Pasta | O que é |
|---|---|
| [`index.html`](index.html) | Página da disciplina: ementa, objetivos, unidades, aulas, avaliação e materiais |
| [`aulas/`](aulas/) | Uma página por aula, com conceitos, estudo de caso, laboratório e checklist |
| [`quiz/`](quiz/) | Quiz de segurança na AWS e simulado no estilo da certificação SCS-C02 |
| [`materiais/apis/`](materiais/apis/) | Atividade extra sobre segurança de APIs e serviços em nuvem |
| `assets/` | Visual comum aos sites da Stela (placa de circuito, tema claro e escuro, chuva de 0 e 1) |

## Como a disciplina funciona

- Laboratórios na **AWS Academy**, com o **Microsoft Learn** mostrando como cada pilar é resolvido no Azure.
- O curso **Cloud Security Foundations** (AWS Academy) é a atividade a distância (10h).
- Toda aula tem um **estudo de caso**: incidentes reais, com fonte, ou clientes fictícios.
- Regra de ouro: credencial nunca vai para o código, nem para ferramenta de IA.

## Tecnologia

HTML, CSS e JavaScript puros, sem framework e sem etapa de build. Acessível: tema claro e escuro, aumento
de texto e botão para pausar as animações em todas as páginas.

Feito com ♥ e sucata eletrônica.
